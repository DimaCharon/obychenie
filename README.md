# Duo-AI 🦉 — персональный ИИ-учитель в стиле Duolingo

Приложение, в котором **человек вводит тему, которую не понимает**, а ИИ:
1. проводит **опрос** (сколько лет, класс/курс, что уже знаешь, что не понятно, какая цель);
2. задаёт **3 уточняющих вопроса** (их придумывает сам ИИ);
3. составляет **персональный план обучения** — разделы, темы, объяснения простым языком и тесты;
4. ведёт по **карте пути** как в Duolingo: темы открываются по одной, за пройденные дают XP и звёзды;
5. внутри урока объясняет материал, а после теста делает **разбор ошибок**;
6. показывает **отчёт об успеваемости** — по курсу целиком и отдельно по каждой теме.

Работает по вашему API: `https://inference.dahl.global/v1` (OpenAI-совместимый),
модель по умолчанию `deepseek-ai/DeepSeek-V4-Flash-0731`.

---

## Быстрый старт

```bash
cd duo-ai
node server.js            # http://localhost:8080
```

Откройте приложение → раздел **«Ключ ИИ»** → вставьте API-ключ → «Сохранить» → «Проверить подключение».
Быстрее — через переменные окружения (они имеют приоритет над файлом):

```bash
AI_API_KEY=ваш_ключ node server.js
```

Без ключа работает **демо-режим**: план, объяснения и тесты генерируются шаблонно, чтобы механику можно было посмотреть сразу.

Требования: Node.js 18+ (используется встроенный `fetch`). Обязательных зависимостей нет: `undici` — опциональный (нужен только для прокси хостинга).

## Деплой на RelaxDev

Проект подстроен под правила платформы ([relaxdev.ru/docs](https://relaxdev.ru/docs)):

| Правило платформы | Что сделано в коде |
|---|---|
| Контейнер принимает трафик только на порту из `PORT` (платформа ставит `8080`), иначе домен вернёт 502 | `PORT` читается из окружения: `PORT` → `SERVER_PORT` → `8080`; привязка к `0.0.0.0`. Захардкоденных портов нет |
| Платформа подставляет **заглушку** `auto-generated-stub-for-build` вместо отсутствующих `process.env.X`, поэтому `process.env.X \|\| 'дефолт'` не работает | Все обращения к окружению идут через `envStr()`/`envInt()`, которые отбрасывают пустые значения, заглушку и `NaN`. Переменные читаются динамически (`process.env[name]`), так что заглушка в них вообще не подставляется |
| Node-fetch (undici) игнорирует `HTTP_PROXY`/`HTTPS_PROXY`, нужен явный диспетчер | Если задан `RELAXDEV_PROXY_URL` (или `HTTP(S)_PROXY`), приложение поднимает `EnvHttpProxyAgent`/`ProxyAgent` из `undici`. Адрес из `RELAXDEV_PROXY_URL` дополнительно прописывается в стандартные переменные — иначе `EnvHttpProxyAgent` его не видит. Если `undici` не установлен, приложение работает напрямую и пишет предупреждение в лог |
| Секреты — в переменных окружения проекта | `AI_API_KEY`, `AI_BASE_URL`, `AI_MODEL` читаются из окружения и перекрывают файл `config.json`. Если каталог только для чтения — понятное предупреждение в интерфейсе вместо ошибки |
| Мониторинг и авто-перезапуск | Есть `GET /health` (статус, порт, режим ИИ, способ хранения, прокси), в `Dockerfile` — `HEALTHCHECK`, обработка `SIGTERM`/`SIGINT` |
| Долгие ответы и прокси-таймауты | `keepAliveTimeout = 65 c`, `headersTimeout = 70 c` (выше, чем у Traefik), таймаут запроса к ИИ — 180 c |

### Как задеплоить

1. **Добавить проект** → выбрать репозиторий с папкой `duo-ai` (или указать её как `rootDir`, если это монорепо).
2. Оставить **«Автоопределение стека»**: платформа увидит Node.js и выполнит `npm install` → `npm start`.
   Если нужен полный контроль — выберите **«Свой Dockerfile»**: в репозитории есть готовый `Dockerfile` (node:20-alpine, `EXPOSE 8080`, healthcheck).
3. Во вкладке **«Переменные»** добавить:

   | Ключ | Значение |
   |---|---|
   | `AI_API_KEY` | ваш ключ к `inference.dahl.global` (обязательно — иначе демо-режим) |
   | `AI_BASE_URL` | `https://inference.dahl.global/v1` (можно не задавать — это значение по умолчанию) |
   | `AI_MODEL` | `deepseek-ai/DeepSeek-V4-Flash-0731` (можно не задавать) |
   | `RELAXDEV_PROXY_URL` | адрес прокси из поддержки — **только** если внешний API обрывает соединения; внутренние адреса платформа исключит сама через `NO_PROXY` |

   `PORT` задавать не нужно — платформа проставит его сама.
4. Нажать **«Деплой»** и открыть `{имя-проекта}.relaxdev.ru`.

Проверка после выката: `https://ваш-домен/health` должен вернуть `{"ok":true,…}` с полем `ai.configured: true`,
а в разделе «Ключ ИИ» кнопка «Проверить подключение» — зелёный ответ `pong`.

### Что не требуется

База данных и Redis не нужны: прогресс ученика хранится в его браузере (`localStorage`).
Если понадобится общий прогресс между устройствами — можно добавить PostgreSQL (в коде для этого есть готовая точка: `store.js` + `/api/*`).

## Тесты

```bash
npm test          # 19 тестов: правила хостинга, маршруты, ИИ-прокси (node:test, без зависимостей)
npm run test:e2e  # 20 проверок в реальном браузере (Playwright) — весь путь пользователя
```

**`npm test`** (10 секунд, ничего доустанавливать не нужно):

- *порт и окружение:* слушает порт из `PORT`; заглушка `auto-generated-stub-for-build` в `PORT` → 8080; мусор в `PORT` → 8080 (а не `NaN`); заглушки в `AI_*` → демо-режим и дефолтный upstream, `/api/ai` отвечает `428 NO_KEY`, а не падает;
- *маршруты и статика:* `/health` со всеми полями; `index.html`/CSS/JS; SPA-fallback; `404` для неизвестного API; сохранение, маскирование и удаление ключа; приоритет ключа из окружения (и запрет его удаления — `409`); `SIGTERM` завершает процесс; `keepAliveTimeout ≥ 60 c`;
- *прокси:* старт с `RELAXDEV_PROXY_URL` и режим прокси в `/health`; **живой CONNECT-прокси** — доказывает, что трафик реально идёт через прокси (а не напрямую);
- *ИИ-прокси (E2E через локальный мок `tools/mock-ai.js`):* `/api/ping` = `pong`; генерация плана (JSON в ```-обёртке доходит целиком и парсится); обычный чат без JSON; ошибка upstream `401` → `502` с текстом; недоступный upstream → понятная сетевая ошибка.

**`npm run test:e2e`** (35 секунд): поднимает мок-ИИ и приложение на свободном порту, проходит в браузере
главная → мастер → уточняющие вопросы ИИ → план (проверяется, что курс собран именно ИИ: 3 раздела, 9 тем) →
карта пути с закрытыми темами → урок (теория → тест → объяснения) → начисление XP → ИИ-чат → разборы от ИИ по курсу и по теме →
настройки → профиль → мобильная вёрстка, и следит за ошибками в консоли.

Playwright для E2E ставится отдельно (в зависимости проекта не входит, чтобы не утяжелять деплой):

```bash
npm i -D playwright && npx playwright install chromium
```

## Как устроено

```
duo-ai/
├─ server.js              # статика + прокси к ИИ (/api/*). Ключ живёт только на сервере
├─ Dockerfile             # образ для хостинга (PORT=8080, healthcheck)
├─ public/
│  ├─ index.html
│  ├─ css/styles.css      # тёмная тема Duolingo: карта, узлы-«зубцы», кнопки с 3D-подъёмом
│  └─ js/
│     ├─ ai.js            # клиент ИИ, промпты учителя, демо-генератор (Mock)
│     ├─ store.js         # курсы, прогресс, XP, стрик, статистика (localStorage)
│     ├─ ui.js            # DOM-хелпер h(), тосты, модалки, конфетти, SVG (зубчатый круг, кольцо)
│     ├─ screens.js       # экраны: главная, мастер, карта, урок, тест, отчёты, настройки, профиль
│     └─ app.js           # роутер (hash) и оболочка: сайдбар, рейл, нижняя навигация
├─ tests/                 # автотесты (node:test + Playwright-сценарий)
└─ tools/mock-ai.js       # локальный «ИИ» для отладки без ключа
```

### Маршруты

| Адрес | Что это |
|---|---|
| `#/` | главная, ввод темы, мои курсы, статистика |
| `#/new?topic=…` | мастер из 5 шагов (тема → кто ты → о тебе → знания → уточнения ИИ) |
| `#/course/<id>` | карта пути: разделы, темы, тропы, бонусный узел |
| `#/lesson/<курс>/<тема>` | урок: теория → главное → тест |
| `#/test/<курс>/<тема>` | сразу тест (и кнопка «новые вопросы от ИИ») |
| `#/report/<курс>` | отчёт по курсу: цифры, график XP, разбор от ИИ, таблица тем |
| `#/report/<курс>/<тема>` | отчёт по теме: история попыток, ошибки, разбор |
| `#/profile` | уровень, стрик, достижения, календарь активности |
| `#/settings` | Base URL, модель, API-ключ, проверка подключения, экспорт/сброс прогресса |

### Схема ИИ-вызовов (все — через `/api/ai`, ключ на сервере)

| Что | Когда | Формат ответа модели |
|---|---|---|
| `Prompts.interview` | шаг 5 мастера | `{questions:[{q, options[], allow_custom}]}` |
| `Prompts.plan` | «Составить план» | `{title, emoji, summary, sections:[{title, subtitle, color, topics:[{title, subtitle, emoji, level, teaches[], theory[{h,body}], quiz[{q,options[],answer,explain}]}]}]}` |
| `Prompts.topic` | тема без материала, «новые вопросы» | `{theory:[…], quiz:[…]}` |
| `Prompts.extra` | «Разобрать ошибки» | `{analysis, quiz:[…]}` |
| `Prompts.bonus` | бонусный узел | `{title, task, checklist[]}` |
| `Prompts.report` | отчёты (курс/тема) | `{verdict, strengths[], weak[], recommendations[], grade}` |
| свободный чат | кнопка «🤖 Спроси ИИ» в уроке | обычный текст |

Ответ модели парсится «мягко»: снимается markdown-обёртка, чинятся висячие запятые и незакавыченные ключи,
при неудаче — вторая попытка, и только потом фолбэк в демо-режим. Приложение никогда не «залипает» на ошибке ИИ.

### Прогресс

Хранится локально в браузере (`localStorage`, ключ `duoai.state.v1`): темы, лучший результат, попытки, время, ошибки, XP по дням, стрик, чаты, отчёты ИИ. В настройках есть экспорт в JSON и полный сброс.

Тема считается пройденной с **70 %**. XP: 20 + 15·результат за урок, 60 — бонус, 25 — разбор ошибок.
Звёзды: 3 — 100 %, 2 — от 80 %, 1 — от 70 %.

## API (бэкенд)

| Метод | Путь | Назначение |
|---|---|---|
| `GET` | `/health`, `/api/health` | статус: версия, аптайм, порт, режим ИИ, хранилище, прокси |
| `GET` | `/api/config` | есть ли ключ, его маска, источник ключа, Base URL, модель |
| `POST` | `/api/config` | сохранить `{apiKey, baseUrl, model}` или `{clear:true}` |
| `POST` | `/api/ai` | `{system, user, json, temperature, maxTokens}` → `{text, usage, ms}` |
| `POST` | `/api/ping` | проверка ключа коротким запросом к модели |

Ключхранится в `data/config.json` (права `600`) или, что предпочтительно на хостинге, приходит из `AI_API_KEY`.

```bash
curl http://localhost:8080/api/ai \
  -H 'Content-Type: application/json' \
  -d '{"system":"Ты учитель","user":"Объясни проценты за 30 секунд","maxTokens":300}'
```

## Демо-ИИ для отладки (без ключа)

```bash
node tools/mock-ai.js          # http://localhost:8999/v1
```

Поднимает OpenAI-совместимый эндпоинт с правдоподобными ответами (план, интервью, разбор ошибок, отчёт).
Укажите в «Настройках» Base URL `http://localhost:8999/v1` и любой ключ (`mock-key`) — весь цикл пройдёт без обращений к настоящей модели.

## Что где менять

- **Стиль ИИ-учителя** — `TEACHER_RULES` в `public/js/ai.js`.
- **Структура плана** (разделы, темы, вопросы) — текст в `Prompts.plan`.
- **Порог прохождения, XP, звёзды** — `PASS`, `saveResult`, `starsFor` в `public/js/store.js`.
- **Цвета и тема** — CSS-переменные в начале `public/css/styles.css`.
- **Модель по умолчанию** — `DEFAULT_MODEL` в `server.js` или переменная `AI_MODEL`.

Скриншоты интерфейса — в папке `screenshots/`.
